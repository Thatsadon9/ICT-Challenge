# ICT Study Room

เว็บติวภาษาไทยสำหรับเตรียม ICT Challenge 2026 แบบ static HTML/CSS/JavaScript ใช้ได้โดยไม่ต้องมีบัญชีหรือ API key

## เปิดใช้

บน macOS ดับเบิลคลิก `เปิดเว็บติว.command` หรือรัน:

```bash
python3 start.py
```

เปิด `http://127.0.0.1:8765` ถ้าปิดเซิร์ฟเวอร์แล้วให้เปิดใหม่ก่อนเรียน ต้องเสิร์ฟผ่าน HTTP เพื่อให้ JavaScript modules และ Python worker ทำงาน จึงไม่เปิด `index.html` ผ่าน `file://` โดยตรง

## มีอะไรบ้าง

- 17 บทมี pre-test ก่อนเรียนทั้งหมด เส้นทางเร่งด่วนเลือก 10 บทหลักจาก 4 หมวด
- Pre-test ใหม่ 85 ข้อ (บทละ 5) ต้องได้อย่างน้อย 4/5 และถูกข้อแกนทั้ง 2 ข้อ จึงเลือกข้ามได้ เกณฑ์นี้เป็นของหลักสูตร ไม่ใช่เกณฑ์คัดเลือกจริง
- ถ้าพลาด/ไม่มั่นใจ เลือกติวเฉพาะช่วงที่เกี่ยวข้อง มีสรุปแก่นและตัวอย่าง แล้วใช้โจทย์ยืนยันชุดใหม่ 51 ข้อ (บทละ 3) ที่แยกจาก pre-test
- เก็บผล pre-test ครั้งแรกแยกจากคำตอบฝึกซ้ำ ไม่ใช้การจำเฉลยมาเปลี่ยนผลก่อนเรียน
- ตัวทดลองเลขฐานสอง เส้นทางเว็บ Cloud ความแม่นยำของโมเดล และการคัดลอกสูตร spreadsheet
- รวม 188 ข้อฝึกไม่ซ้ำ: pre-test 85 + โจทย์ยืนยัน 51 + ข้อเดิม 52 ข้อ แบบฝึกพื้นฐานเดิมเป็นตัวเลือก ไม่บังคับทำซ้ำเพื่อผ่านบท
- ชุดรวมประยุกต์ 10 ข้อจากโจทย์ยืนยันหลายบท, อุ่นเครื่อง 10 ข้อ และวัดพื้นฐานเดิม 20 ข้อ มีตัวจับเวลา ผลแยกหมวดและเหตุผล
- 6 โจทย์ Python มี custom stdin, test cases, expected/actual, traceback, ปุ่มหยุด และ timeout 8 วินาที
- บันทึกความคืบหน้า คำตอบและโค้ดใน localStorage; export/import JSON และทบทวนข้อผิดพร้อมโน้ต

เนื้อหา ข้อฝึก ตัวรัน Python และฟอนต์รวมอยู่ในโฟลเดอร์นี้ ไม่ต้องเชื่อมต่ออินเทอร์เน็ตระหว่างเรียนบน local server ยกเว้นเมื่อกดลิงก์อ่านแหล่งข้อมูลภายนอก

ไม่มีการส่งโค้ดไปตรวจบน backend: Python ทำงานใน Web Worker ผ่าน Pyodide 314.0.7 ตัวทดสอบใช้ข้อมูลที่ระบุไว้ใน `challenges.js` และเปรียบเทียบ output โดยละเว้น whitespace ท้ายบรรทัด/ท้ายข้อความ ไม่ใช่ระบบ judge ที่ป้องกันการทุจริตหรือพิสูจน์ความถูกต้องกับทุก input และไม่รองรับรัน C/Java ใน editor; มีเนื้อหาอ่านโค้ด C/Java ในบทเรียน

## โครงสร้าง

สำหรับ Vercel ให้ import จากราก repository โดยใช้ `vercel.json` และขั้นตอนใน [README หลัก](../README.md#host-บน-vercel) คำสั่ง `npm run build` จากโฟลเดอร์นี้สร้าง static site ใน `../dist/` โดยไม่รวมไฟล์ QA หรือข้อมูลความคืบหน้าในเครื่อง

- `lessons.js`: เนื้อหา 17 บทและโจทย์เพิ่มเติม
- `assessment.js`: pre-test, โจทย์ยืนยัน, สรุปแก่น, ลำดับเร่งด่วน และเกณฑ์คำนวณผล
- `data/questions.json`: ข้อฝึกเดิมที่นำเข้าจาก Markdown
- `challenges.js`: คำอธิบาย starter, hint, solution และ test cases
- `app.js`: หน้าจอ การเรียน แบบฝึก state และตัวควบคุม worker
- `python-worker.js`: ตัวรัน Python แยกจาก UI
- `scripts/import_questions.py`: นำเข้าข้อฝึกจากเอกสารต้นทาง (รันจาก checkout นี้)
- `assets/pyodide`: runtime ที่จัดเก็บไว้ในเครื่อง

ความคืบหน้าผูกกับ browser และ origin (รวม port) ที่ใช้ เปิดที่อยู่เดิมเพื่อเรียนต่อ หรือ export แล้ว import เมื่อต้องย้ายเครื่อง/เบราว์เซอร์ การล้าง browser data จะลบข้อมูลที่บันทึกไว้

การข้ามบทบันทึกเป็น `completionMethod: pretest` โดยไม่ปลอมว่าอ่านทุกช่วงหรือผ่านโจทย์เขียนโปรแกรม เส้นทางเร่งด่วนสำหรับออนไลน์ไม่บังคับเขียนโปรแกรม ส่วนเส้นทางเต็มยังมีโจทย์โค้ดให้ฝึก สถานะการผ่านโค้ดแยกจากผลปรนัยเดิม
