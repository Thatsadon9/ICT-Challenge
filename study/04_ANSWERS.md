## เฉลยชุด M

### M1: A, C, D

DHCP ให้ค่าตั้งเครือข่าย ส่วน router ส่ง packet ระหว่าง network และ Ethernet switch ส่ง frame ภายใน LAN โดยพิจารณา MAC ตัวเลือก B สลับหน้าที่ DNS กับ DHCP

### M2: B

ใช้แอปสำเร็จรูปจึงเป็น SaaS แม้ผู้ใช้ต้องสร้างบัญชีและกำหนดสิทธิ์เอง ความรับผิดชอบบางส่วนของผู้ใช้ไม่ได้เปลี่ยน SaaS ให้เป็น IaaS

### M3: B, D

Password เป็นสิ่งที่รู้และ hardware security key เป็นสิ่งที่มี จึงเป็นตัวอย่างคนละปัจจัย ส่วน PIN กับ password อยู่กลุ่มสิ่งที่รู้เหมือนกัน HTTPS ปกป้องการสื่อสารตาม TLS และตรวจปลายทางตาม certificate แต่เว็บหลอกลวงก็ใช้ HTTPS ได้ จึงไม่รับประกันความสุจริต Encryption ออกแบบให้ถอดกลับด้วยกุญแจ ส่วน hashing ออกแบบเพื่อ digest และย้อนกลับยาก

### M4: C — 12

| รอบ i | x ก่อน | คำสั่ง | x หลัง |
|---|---|---|---|
| 0 | 1 | 1×2+0 | 2 |
| 1 | 2 | 2×2+1 | 5 |
| 2 | 5 | 5×2+2 | 12 |

ต้องใช้ค่า x ที่อัปเดตจากรอบก่อน ไม่เริ่ม x=1 ใหม่ทุกครั้ง และ range(3) เริ่มที่ 0

### M5: C

Input `[1,2,4]` เข้ารอบแรก value=1 ไม่ใช่เลขคู่ จึงไม่เพิ่ม count แล้ว return 0 ทันที ไม่ได้ตรวจ 2 และ 4 ควรย้าย return ออกนอกลูป:

```python
def count_even(values):
    count = 0
    for value in values:
        if value % 2 == 0:
            count += 1
    return count
```

ให้ทดสอบ `[1,2,4]→2`, `[1,3]→0`, `[2]→1`, `[]→0` และ `[-2,0,3]→2` เพื่อยืนยันว่าตรวจทุกตัวและรับกรณีไม่มีสมาชิกได้

### M6: C

กรณีแย่สุดตรวจครบ n ตัว เช่น ไม่พบค่าที่หา จึงเป็น O(n) ไม่ใช่ O(log n) เพราะไม่ได้ตัดช่วงครึ่งหนึ่ง ส่วนกรณีเจอตัวแรกอาจจบเร็ว แต่ไม่ใช่กรณีแย่สุดที่โจทย์ถาม

### M7: A — 75%, 90%

Precision = 18/(18+6) = 75%; recall = 18/(18+2) = 90% ไม่ต้องรู้ TN เพื่อคำนวณสองสูตรนี้ ถ้าถาม accuracy จึงต้องมีจำนวนรวมที่รวม TN

### M8: B, C, D

Feature ต้องมีจริงเมื่อจะทำนาย การใส่คะแนนสอบที่ยังไม่เกิดทำให้ข้อมูลอนาคตรั่ว การปรับโมเดลตาม test ซ้ำ ๆ ทำให้ test ไม่ได้เป็นชุดประเมินที่เป็นอิสระจากกระบวนการเลือกโมเดลอีกต่อไป

### M9: C — `=$A3*C$1`

ย้ายขวา 1 ลง 1: `$A2` ล็อกคอลัมน์ A แต่แถว 2 เลื่อนเป็น 3; `B$1` คอลัมน์ B เลื่อนเป็น C แต่แถว 1 คงเดิม

### M10: B, C, D

ค่าว่างอาจหมายถึงไม่บันทึก ไม่ทราบ หรือใช้ไม่ได้ จึงแทนเป็นศูนย์ทุกกรณีไม่ได้ CSV ไม่เก็บองค์ประกอบ workbook ครบเหมือน XLSX Automation ต้องวางวิธีรับมือข้อมูลผิดหรือซ้ำ และการ sort แยกคอลัมน์อาจทำลายความสัมพันธ์ของแต่ละแถว
